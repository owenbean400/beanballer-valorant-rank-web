# 🧠💥 BeanBaller — Valorant Player Game Website

Check it out here 👉 [**beanballer.com**](https://www.beanballer.com)

Welcome to **BeanBaller**, a Valorant-themed website built to showcase gameplay highlights, match history, AI-powered insights, and more — all centered around the player **BeanBaller** 🕹️

---

## ⚙️ Technology Stack

**Built With:**
- 🧱 HTML  
- 🎨 SASS  
- 💻 JavaScript (with **Vue.js**)  

**Hosted on:** ☁️ **AWS S3**

### 🧩 Compile SASS
To compile styles, run:
```bash
sass style.sass style.css
```

## 🚀 Backend Projects

Here's the power behind the scenes:

- 🔗 [BeanBaller API](https://github.com/owenbean400/valorant-rank-aws-api) Handles gameplay stats, rank data, and match info.

- 🤖 [BeanBaller AI API](https://github.com/owenbean400/valorant-rank-ai-aws-lamda) Uses AI to analyze BeanBaller's latest matches and answer your questions.
